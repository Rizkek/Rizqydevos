# Vision

> **DevOS is a personal command center for software engineers.**

---

## What is DevOS?

DevOS is a self-hosted developer operating system built for a single purpose:
to give a software engineer a unified, powerful workspace where every tool,
every workflow, and every piece of context lives in one place.

It is not a SaaS product. It is not a productivity app for the general public.
It is a **Mission Control** — the kind of environment where an engineer can open
one URL and immediately understand the state of everything they care about.

---

## The Core Idea

A modern software engineer context-switches constantly:

- Writing code → reviewing PRs → checking deployments
- Learning new concepts → taking notes → building knowledge
- Monitoring servers → checking logs → responding to alerts
- Managing tasks → planning sprints → tracking progress
- Researching AI models → writing prompts → testing agents

DevOS is the **single environment** where all of this happens — or at minimum,
where all of it is visible. Not by replacing the specialized tools, but by
surfacing what matters, when it matters, in one coherent interface.

---

## The Feeling

When someone opens `rizky.web.id`, the impression should be immediate:

> **"This is the command center of a software engineer."**

Not a career app. Not a finance dashboard. Not a clone of Notion or Linear.
Something that feels purpose-built, opinionated, and deeply personal.

---

## Inspiration

DevOS draws inspiration from tools that have redefined their respective domains:

| Tool | What We Borrow |
|------|---------------|
| **Linear** | Clean, fast project and task management |
| **Raycast** | Launcher-like speed, keyboard-first productivity |
| **GitHub** | Developer activity as the center of the experience |
| **Obsidian** | Knowledge as a living, interconnected graph |
| **Postman** | API collections, organized and always accessible |
| **Grafana** | Monitoring as a first-class experience |
| **Portainer** | Container management made visual and intuitive |
| **Cloudflare Dashboard** | Security and infrastructure in one glance |

DevOS is not a copy of any of these. It is what happens when one engineer
decides to build their own version of all of them — integrated, self-hosted,
and deeply personalized.

---

## Relationship with TRASON

DevOS and TRASON are **complementary, not competing**.

| Dimension | TRASON | DevOS |
|-----------|--------|-------|
| Purpose | Career management platform | Developer workspace |
| Audience | Any user | Rizky (the developer) |
| Model | SaaS product | Personal / open source |
| Scope | Job search, ATS, resume, interview | Code, infra, knowledge, AI |
| Identity | Product | Operating System |

Career and finance features in DevOS exist only as **status widgets** —
a personal snapshot, not a management system. The deep career tooling
lives in TRASON. DevOS only shows what is relevant right now.

---

## Three-Year Vision

In three years, DevOS should be:

1. **The only tab that needs to be open** — everything a developer needs
   visible from one interface.
2. **A living portfolio piece** — proof that its creator understands
   frontend, backend, infrastructure, AI, security, and design at a
   professional level.
3. **A reusable framework** — the architecture, engineering standards,
   and AI agent system built for DevOS should be portable to any future
   project.
4. **A reference implementation** — other developers should be able to
   look at DevOS and learn how a production-grade personal system is built.
