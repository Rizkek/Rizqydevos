# DevOS

> **A personal command center for software engineers.**

```
rizky.web.id
```

---

## What is this?

DevOS is a self-hosted developer operating system. One URL. Every tool,
every workflow, every piece of context — in one place.

Built by a software engineer, for a software engineer.

---

## Modules

| Module | Purpose |
|--------|---------|
| **Dashboard** | Mission Control — today at a glance |
| **Projects** | Active development projects registry |
| **Workspace** | Todo, Kanban, Notes, Calendar, Scratchpad |
| **Knowledge** | Snippets, library, learning, reading list |
| **Developer** | GitHub, Docker, API, Terminal, SSH |
| **Infrastructure** | Servers, Vercel, Cloudflare, Supabase |
| **Security** | Secrets, audit, SSL, dependencies |
| **Monitoring** | Metrics, logs, alerts, uptime |
| **AI** | Prompts, agents, RAG, automation |
| **Analytics** | Personal productivity and activity stats |
| **Automation** | Workflows, cron, webhooks |
| **Settings** | Preferences and integrations |

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js + TypeScript |
| UI | Tailwind CSS + shadcn/ui |
| State | TanStack Query + Zustand |
| Backend | NestJS |
| Database | PostgreSQL + Prisma |
| Cache | Redis |
| Auth | Better Auth (passkey + OAuth) |
| Queue | BullMQ |
| Monitoring | OpenTelemetry + Grafana |
| Deployment | Docker + Coolify |
